# Ninnis Engineering System (NES)

Version: 1.0

---

# Mission

The Ninnis Engineering System (NES) is an evidence-driven engineering methodology.

Its purpose is not simply to build good software.

Its purpose is to build good engineers.

Every project should improve:

- the software
- the engineering process
- the engineer

---

# Philosophy

Software engineering is not guessing.

Software engineering is observation.

NES encourages engineers to:

- Observe before changing.
- Collect evidence before concluding.
- Understand the mechanism before fixing it.
- Verify every change.
- Learn from every investigation.

---

# Vision

NES aims to create software that explains itself.

Instead of asking:

"What do we think happened?"

NES asks:

"What evidence do we have?"

---

# Core Values

Evidence

Facts before assumptions.

Observation

Watch the system before changing it.

Curiosity

Every bug teaches something.

Learning

Every investigation improves engineering judgement.

Simplicity

The simplest proven solution is usually the best.

Responsibility

Every engineer leaves the project easier to investigate than they found it.
